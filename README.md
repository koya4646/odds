# Odds Party 🏇

友達同士で競馬のような予想・投票を楽しめる、スマホ対応Webアプリケーション。

## 🌟 特徴 & 実装機能

1. **ルーム管理**
   - ホストによるルーム作成（ルーム名、ホスト名、初期所持ポイント、控除率設定）
   - 6文字の参加コードによる入室、ワンタップ招待URL・メッセージコピー
   - ルーム内参加者一覧・ホスト判定

2. **ポイント管理**
   - 現金や換金なしの純粋なゲーム用ポイント
   - 開催（レース）をまたいでポイントを完全引き継ぎ
   - 投票時に即時減算、的中精算時に払い戻し加算

3. **開催設定 (レース / イベント)**
   - 投票対象（タイトル）、出走者/選択肢（自動枠番カラー付き）、控除率（0〜50%）、目安締切時間の設定
   - 設定を「テンプレート」として保存・複製可能（次回からワンクリック作成）
   - 券種設定（単勝、馬連、馬単）

4. **事前予想 & 初期オッズ算出**
   - 参加者が仮想予想ポイントを各出走者に配分して提出
   - 計算式：`初期オッズ ＝ 予想ポイント総額 × (1 − 控除率) ÷ 対象への予想ポイント`
   - 他の参加者の予想内容・配分ポイントも「みんなの予想」画面でリアルタイム閲覧可能

5. **投票 (ベッティング)**
   - 所持ポイントの範囲内で自由なポイントを投票
   - マークカード風UIで単勝・馬連・馬単を選択し、購入カートに追加
   - 複数の買い目をまとめて一括投票購入可能（マルチ投票）
   - 二重投票や残高不足の自動バリデーション

6. **オッズ表示**
   - 投票状況に応じてオッズがリアルタイムに変動
   - 計算式：`投票オッズ ＝ 投票総額 × (1 − 控除率) ÷ 対象への投票額`
   - ホストが締め切った時点でオッズを固定（スナップショット保存）
   - 表示時は小数点第1位に丸め、計算内部では高精度を維持

7. **結果・精算**
   - ホストが着順結果（1着・2着）を入力し、正解判定＆払い戻し実行
   - 払い戻し額 ＝ 投票額 × 締切時オッズ（外れは0）
   - **的中者がいない場合：初期設定で投票ポイントを全額返金**
   - 的中時の紙吹雪演出（canvas-confetti）
   - 精算済みフラグによる二重精算防止

8. **履歴 & ランキング**
   - 通帳形式でポイント増減（初期付与・投票・払い戻し・返金）と残高推移を記録
   - 過去の全投票チケットの判定結果閲覧
   - ルーム内ランキング（現在ポイント順位表、増減額、回収率、的中率、的中数）

9. **Supabase 連携 & タブ間同期**
   - 未設定でも同一ブラウザの複数タブ間（BroadcastChannel）で即座にリアルタイム同期
   - SupabaseのProject URLとAnon Keyを入力すれば、スマートフォン・複数端末間でのリアルタイム同期に対応
   - `supabase/schema.sql` を同梱

## 🚀 起動方法

### 依存関係のインストール & 開発サーバー起動
```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

### プロダクションビルド
```bash
npm run build
npm run preview
```

---

## 🗄️ Supabase のセットアップ（任意・複数端末で遊ぶ場合）

1. [Supabase](https://supabase.com/) で新規プロジェクトを作成
2. 左メニューの「SQL Editor」を開く
3. 本プロジェクトの `supabase/schema.sql` の内容を貼り付けて「Run」を実行
4. アプリ右上の「データベースアイコン」をクリックし、Project URL と Anon Key を入力して「保存」
